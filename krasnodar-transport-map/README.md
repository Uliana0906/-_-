# Поездки на человека в год — Краснодарский край, 2025

Интерактивная тематическая карта транспортной мобильности Краснодарского края.
Каждый населённый пункт с доступными данными Росстата изображён оригинальным
картографическим знаком — **верстовым столбиком** на круглом основании:

- **Высота столбика** — число поездок на человека в год (линейная шкала
  относительно максимума, с минимальной высотой для читаемости малых значений).
- **Диаметр основания** — численность населения (масштабирование по квадратному
  корню: *площадь* платформы пропорциональна числу жителей, крупные города
  не доминируют чрезмерно).

## Открыть карту

**[Открыть карту](index.html)** — просто откройте `index.html` в браузере
или разверните через GitHub Pages (см. ниже).

## Данные

| Показатель | Источник | Год |
|---|---|---|
| Поездки на человека в год, автобусы, перевезённые пассажиры, пассажирооборот | Росстат, федеральное статистическое наблюдение за автомобильными перевозками | 2025 |
| Численность населения населённых пунктов | Росстат (в составе того же набора данных, сопоставление по ОКТМО) | 2025 |
| Координаты населённых пунктов | Исходный набор данных (Широта/Долгота, WGS84) | — |
| Граница Краснодарского края | OpenStreetMap (Nominatim, relation 108082) | — |

Исходный файл: `краснодарский_край_транспорт_2025 (1).csv` (108 записей).
Из них **30 населённых пунктов** имеют непустое значение показателя «Поездок
на человека в год» и показаны на карте; 78 записей без значения (или без
координат) скрыты — так решено при проектировании карты. Населённые пункты
не заменялись административными центрами районов: используются фактические
координаты каждого НП из набора.

Подложка — **CartoDB Positron**, обслуживаемый OpenFreeMap
(`https://tiles.openfreemap.org/styles/positron`): тот же открытый стиль
Carto, но без API-ключа. Растровые тайлы CARTO (`basemaps.cartocdn.com`)
с 2025 года требуют ключ (иначе рисуют водяные знаки); если нужен именно
CARTO как провайдер — получите ключ на <https://carto.com/basemaps/apikey/>
и замените `style_url` в `scripts/build_map.py` на URL стиля с ключом.

## Технологии

- [LLMaps 2.0](https://github.com/greadr71/LLMaps) (рецепт `points-sized`,
  расширенный custom JS через официальные hook'и `add_custom_js/html/css`)
- MapLibre GL JS 5 (fill-extrusion 3D-столбики, круговые основания, подписи)
- Один автономный HTML-файл: данные GeoJSON встроены (geobuf + pako)

### Шкалы кодирования

- Высота: `h = 80 + v/v_max · 1120` метров (v_max = 773,7 — с. Борисовка),
  на карте высота и footprint столбиков показаны с единым коэффициентом
  преувеличения (высота ×60, основание ×5), к глубоким зумам столбики
  плавно растворяются, оставляя точные основания и подписи.
- Диаметр: `d = max(150, 700·sqrt(pop/918 145))` метров (макс. — г. Краснодар).

## Воспроизведение

```bash
pip install llmaps
python scripts/fetch_boundary.py   # граница края из OSM (однократно)
python scripts/prepare_data.py     # CSV -> GeoJSON (пути к CSV внутри)
python scripts/build_map.py        # -> index.html
```

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки:
   ```bash
   git init
   git add .
   git commit -m "Карта транспортной мобильности Краснодарского края, 2025"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a
   branch → main / (root) → Save**.
3. Карта будет доступна по адресу `https://<user>.github.io/<repo>/`.

`.nojekyll` уже включён.

## Известные особенности

- При начальной загрузке MapLibre 5.16 молча отбрасывает paint-выражения,
  где `zoom`-интерполяция обёрнута в арифметику (`max`/`+` поверх zoom).
  Все выражения построены так, чтобы `zoom` встречался только в корневом
  `interpolate` (арифметика — внутри стопов), а «умные» слои добавляет
  идемпотентный `ensure()`-цикл, пережидающий инициализацию и
  скрытие/восстановление вкладки.
